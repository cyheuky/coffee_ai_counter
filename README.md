# ☕ Coffee AI Counter

Система автоматизированного учета заказов в кофейне на базе компьютерного зрения (**YOLOv8**) и **Streamlit**.

## 📌 Описание
Приложение анализирует видеопоток с камер над зоной выдачи, детектирует стаканы и бутылки, и автоматически формирует статистику по заказам. Главная особенность — алгоритм **Max Hold**, который считает пиковое количество предметов в кадре, исключая дублирование при проигрывании видео.

## 🚀 Функционал
- **Видео-анализ:** обработка видео с возможностью паузы и продолжения.
- **Детекция:** использование YOLOv8 для поиска чашек (cup) и бутылок (bottle).
- **Статистика:** сохранение данных о каждом заказе в SQLite.
- **Отчетность:** экспорт истории в Excel-таблицу.
